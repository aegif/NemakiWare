## 6. CodeQL の扱い

### 測った結論

**`java/sensitive-log` の群は「識別子のログ」であり、修正では閉じない。**
値を外す処置（強制変換ログ 13 か所、全件ダンプ 2 ブロック）を押したあと再計算したところ、
新しく立った警告 1438〜1446 が乗っている行は **`propertyId` だけを出している**。
CodeQL は CMIS のプロパティ識別子そのものを機微情報として扱う。識別子まで消すと
`TYPE COERCION FAILED for property ''` となり、診断が成り立たない。

したがってこの群は **`won't_fix` で受容する**。受容の文面に書いてはいけないこと
（確認レビューの指摘。本番は `jp.aegif.nemaki=INFO` なので `userId` は INFO/WARN/ERROR に出る）:

- 「機密情報ではない」「PII を含まない」
- 「DEBUG のみ」「本番では出ない」
- 「匿名化・hash・redaction 済み」「admin 専用経路」「悪用可能性がない」
- 無関係な `CoercionAuditLogger` の 200 文字制限を根拠にすること

書くのは「診断のためにこの露出を**承知のうえで受け入れる**」である。
