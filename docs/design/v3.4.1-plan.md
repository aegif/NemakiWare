# v3.4.1 計画 — 3.4.0 の残件パッチ

2026-09-17 起案。3.4.0 リリース時に「分かっていて見送った」項目のうち、**破壊的変更を
伴わないもの**を 3.4.1 として閉じる。

出典は [`fail-closed-reads.md`](fail-closed-reads.md) の残件表と、
[`v3.4-release-readiness.md`](v3.4-release-readiness.md) の分類。
**着手前に必ずコードで再確認すること** — 台帳の文言を正として着手しない
(3.3 で「未修正」の記述が実際には修正済みだった前例、3.4 で R25 の残件の前提そのものが
偽だった前例がある)。

## 判定基準 (3.3.1 計画と同じ)

- 3.4.0 と同じ観測可能な挙動を保つ (不具合修正を除く)
- RELEASE_NOTES に「破壊的変更」節が**増えない**こと
- 各修正は判別するテストを伴う (負のコントロール: 修正を戻すと落ちること)
