## 1. ログイン

1. ブラウザで NemakiWare UI にアクセスします
   - 例: `http://localhost:8080/core/ui/`
2. ユーザー名とパスワードを入力して「ログイン」をクリック

**認証方式:**
- パスワード認証（標準）
- パスキー認証（Touch ID / Face ID / セキュリティキー）
- OIDC（Google / Microsoft 等のクラウド認証）
- SAML（エンタープライズ SSO）

パスキーが登録されている場合は「パスキーでログイン」ボタンが表示されます。

---

## 2. ドキュメント一覧

ログイン後、ドキュメント一覧画面が表示されます。

**画面構成:**
- **左ペイン**: フォルダツリー — クリックでフォルダを選択
- **メインエリア**: 選択したフォルダ内のドキュメントとサブフォルダの一覧
- **パンくずリスト**: 現在のフォルダ階層

**一覧の操作:**
- フォルダ名をクリック → フォルダ内に移動
- ドキュメント名をクリック → 詳細表示
- 「↑」ボタン → 親フォルダに戻る

**表示項目:**
| 列 | 説明 |
|----|------|
| 名前 | ファイル名またはフォルダ名 |
| 更新日時 | 最終更新日 |
| 更新者 | 最終更新ユーザー |
| サイズ | ファイルサイズ |

---

## 3. フォルダ操作

### フォルダの作成

1. 「フォルダ作成」ボタンをクリック
2. フォルダ名を入力
3. 必要に応じてフォルダタイプを選択（カスタムタイプがある場合）
4. 「作成」をクリック

### フォルダの削除

1. フォルダを選択
2. 「削除」ボタンをクリック
3. サブフォルダやドキュメントが含まれる場合は、カスケード削除の確認ダイアログが表示されます

---

## 4. ドキュメントのアップロード

1. 「アップロード」ボタンをクリック
2. アップロードダイアログが開きます
3. ファイルをドラッグ＆ドロップ、または「ファイルを選択」をクリック
4. 必要に応じてドキュメントタイプを選択
5. カスタムプロパティがある場合は値を入力
6. 「アップロード」をクリック

**対応ファイル形式:**
- PDF、Word (.docx)、Excel (.xlsx)、PowerPoint (.pptx)
- 画像 (PNG, JPEG, GIF, SVG)
- テキスト、HTML、XML、JSON
- その他任意のファイル

---

## 5. ドキュメントの詳細表示

ドキュメント名をクリックすると詳細画面が開きます。

**タブ構成:**
| タブ | 内容 |
|------|------|
| プロパティ | CMIS 標準プロパティとカスタムプロパティ |
| プレビュー | ファイル内容のプレビュー |
| バージョン履歴 | 過去のバージョン一覧 |
| セカンダリタイプ | 付与されたアスペクト（メタデータ拡張） |
| 権限 | ACL（アクセス制御リスト） |
| リレーションシップ | 関連ドキュメント |

---

## 6. プレビュー

詳細画面の「プレビュー」タブでファイル内容を確認できます。

**プレビュー対応形式:**
| 形式 | プレビュー方法 |
|------|---------------|
| PDF | ブラウザ内 PDF ビューア |
| Word / Excel / PPT | サーバーサイド変換 → PDF プレビュー |
| 画像 | インラインプレビュー |
| テキスト / JSON / XML | シンタックスハイライト |
| 動画 | ストリーミングプレイヤー |

---

## 7. プロパティの編集

1. 詳細画面の「プロパティ」タブを開く
2. 「編集」ボタンをクリック
3. 変更したいプロパティの値を編集
4. 「保存」をクリック

**読み取り専用プロパティ:**
- `cmis:objectId` — ドキュメントID（自動生成）
- `cmis:createdBy` — 作成者
- `cmis:creationDate` — 作成日時
- `cmis:lastModifiedBy` — 最終更新者
- `cmis:lastModificationDate` — 最終更新日時

---

## 8. バージョン管理

NemakiWare はドキュメントのバージョン管理をサポートしています。

### 新しいバージョンの作成

1. 詳細画面で「チェックアウト」をクリック
2. ファイルを編集
3. 「チェックイン」をクリックし、更新ファイルをアップロード
4. メジャー / マイナーバージョンを選択
5. コメントを入力（任意）

### 過去バージョンの閲覧

1. 「バージョン履歴」タブを開く
2. バージョン一覧から目的のバージョンをクリック
3. そのバージョンのプロパティとプレビューが表示されます

### バージョンのダウンロード

バージョン履歴の各行にダウンロードボタンがあります。

---

## 9. 検索

### 基本検索

1. 画面上部の検索ボックスにキーワードを入力
2. Enter キーまたは「検索」ボタンをクリック
3. ファイル名と本文から検索されます

### 検索のヒント

- 日本語と英語の両方で検索可能
- PDF、Word、Excel の本文テキストも検索対象
- 部分一致検索: キーワードの一部でもマッチ

### セマンティック検索（RAG）

AI ベースの意味検索が有効な場合、関連性の高いドキュメントが優先表示されます。

## 10. セカンダリタイプ（アスペクト）

セカンダリタイプはドキュメントに追加のメタデータを付与する仕組みです。

### セカンダリタイプの追加

1. 詳細画面の「セカンダリタイプ」タブを開く
2. 「追加」をクリック
3. 利用可能なセカンダリタイプから選択
4. 追加後、対応するプロパティが「プロパティ」タブに表示されます

### 例: コメント機能

`nemaki:commentable` セカンダリタイプを追加すると、ドキュメントにコメントを付けられるようになります。

---

## 11. 権限（ACL）の確認

1. 詳細画面の「権限」タブを開く
2. 現在のアクセス制御エントリ（ACE）が一覧表示されます

**権限レベル:**
| 権限 | 説明 |
|------|------|
| `cmis:read` | 閲覧のみ（ダウンロード・プロパティ参照） |
| `cmis:write` | 編集（アップロード・プロパティ変更・バージョン作成） |
| `cmis:all` | 全操作（権限の変更・削除を含むすべての操作が可能） |

> **cmis:all と admin ユーザーの違い**: `cmis:all` はドキュメント/フォルダ単位のアクセス権限です。`admin` ユーザーはシステム管理者（ユーザー/グループ管理、システム設定変更）で、両者は独立した概念です。権限を変更するには、対象に対して `cmis:all` を持っている必要があります。

## 12. クラウドドライブ連携

Google Drive / OneDrive との連携が設定されている場合:

### クラウドからのインポート

1. ドキュメント一覧で「Google Drive からインポート」または「OneDrive からインポート」をクリック
2. クラウドストレージにログイン（初回のみ）
3. インポートするファイルを選択
4. 「インポート」をクリック

**重複検出:**
同じファイルを再度インポートしようとすると「インポートがスキップされました」通知が表示され、既存ドキュメントへのリンクが提供されます。

## 13. パスキー認証

パスワードの代わりに Touch ID / Face ID / セキュリティキーでログインできます。

### パスキーの登録

1. ログイン後、メニューから「アカウント設定」を開く
2. 「パスキー管理」セクションへ移動
3. 「パスキーを追加」をクリック
4. ブラウザの認証プロンプトに従う

### パスキーでログイン

1. ログイン画面で「パスキーでログイン」をクリック
2. ブラウザが Touch ID / Face ID / セキュリティキーの確認を要求
3. 認証成功でログイン完了

> パスキーは HTTPS 環境（または localhost）でのみ利用可能です。

---

## 14. パスワード変更

1. メニューから「アカウント設定」を開く
2. 「パスワード変更」セクション
3. 現在のパスワードと新しいパスワードを入力
4. 「変更」をクリック

---

## 15. 言語切り替え

NemakiWare は日本語と英語に対応しています。

1. 画面右上の言語切り替えボタン（🌐）をクリック
2. 「日本語」または「English」を選択
3. 設定はブラウザに保存され、次回以降も維持されます
